# План: файл сценария, который загружается в админку

## Решение по формату

**Расширение: `.json`** (кодировка UTF-8, имя вида `юбилей-50-мария.json`).

### Почему JSON, а не что-то другое

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **JSON** | нативно читается Flask, есть валидация схемы, легко редактировать в любом редакторе, легко генерировать программно | скобки и кавычки, человеку править чуть менее приятно | **✅ берём** |
| YAML | приятнее человеку | нужна лишняя зависимость `pyyaml`, ошибка в отступе ломает файл молча | нет |
| DOCX / TXT | привычно ведущему | нужно парсить свободный текст, ошибки неизбежны | нет |
| Markdown | читаемо | тот же парсинг свободного текста | нет |

**Компромисс для удобства:** файл `.json`, но **редактируется он не в блокноте, а прямо в админке** — вкладка «Сценарий» с формой: список шагов, у каждого тип, текст, длительность. Кнопки «Скачать .json» и «Загрузить .json». То есть JSON — формат хранения и обмена, а не то, что вы печатаете руками.

## Структура файла

```jsonc
{
  "format": "avatar-host-scenario",
  "version": 1,
  "meta": {
    "title": "Юбилей Марии Петровны — 50 лет",
    "subtitle": "Сканируйте QR и представьтесь",
    "hero": "Мария Петровна",          // юбиляр, подставляется как {hero}
    "author": "Иван",
    "duration_min": 180,
    "voice": "ru-RU-SvetlanaNeural",
    "rate": 0,
    "pitch": 0
  },
  "vars": {                              // подставляются в тексты как {var}
    "город": "Йошкар-Ола",
    "супруг": "Николай"
  },
  "steps": [
    {
      "id": "welcome",
      "title": "Сбор гостей",
      "type": "say",                     // тип шага, см. таблицу ниже
      "text": "Добрый вечер! Я ваш электронный ведущий. Отсканируйте QR-код и представьтесь.",
      "phase": "welcome",
      "accepting": true,                 // открыть приём гостей
      "auto_next": false                 // ждать нажатия «Далее» ведущим
    },
    {
      "id": "greet-all",
      "title": "Приветствие гостей по именам",
      "type": "greet_guests",
      "template": "{name}, добро пожаловать! {hero} вас уже ждёт.",
      "auto_next": false
    },
    {
      "id": "pause-dance",
      "title": "Танцевальная пауза",
      "type": "pause",
      "text": "Объявляется музыкальная пауза! Танцпол ждёт.",
      "minutes": 20,
      "auto_next": false
    },
    {
      "id": "quiz-1",
      "title": "Викторина: кто лучше знает юбиляршу",
      "type": "quiz",
      "intro": "Внимание, конкурс! Отвечайте на телефонах.",
      "seconds": 40,
      "questions": [
        { "q": "В каком городе {hero} встретила {супруг}?",
          "options": ["Казань", "{город}", "Сочи"], "correct": 1 },
        { "q": "Какое блюдо у неё получается лучше всех?",
          "options": ["Пироги", "Плов", "Селёдка под шубой"], "correct": 0 }
      ],
      "outro": "Правильный ответ — {correct}. Угадали {winners}!"
    },
    {
      "id": "toast-family",
      "title": "Слово семье",
      "type": "handoff",                 // аватар объявляет и замолкает
      "text": "Слово предоставляется семье. Микрофон ваш!",
      "auto_next": false
    },
    {
      "id": "poll-1",
      "title": "Опрос: откуда вы знаете юбиляршу",
      "type": "poll",                    // как quiz, но без правильного ответа
      "question": "Откуда вы знаете {hero}?",
      "options": ["Семья", "Работа", "Соседи", "Друзья"],
      "seconds": 30
    },
    {
      "id": "wishes",
      "title": "Книга пожеланий",
      "type": "collect",                 // гости пишут текст с телефонов
      "prompt": "Напишите одно пожелание юбилярше",
      "read_aloud": 5                    // зачитать 5 случайных вслух
    },
    {
      "id": "finale",
      "title": "Финал",
      "type": "say",
      "text": "Спасибо, что были с нами! Лидеры вечера: {leaders}.",
      "phase": "finale"
    }
  ]
}
```

### Типы шагов

| `type` | Что делает | Ключевые поля |
|---|---|---|
| `say` | аватар произносит текст | `text` |
| `greet_guests` | здоровается со всеми неприветствованными по именам | `template` |
| `quiz` | викторина с правильным ответом, начисляет баллы | `questions[]`, `seconds` |
| `poll` | опрос без правильного ответа, показывает столбики | `question`, `options` |
| `collect` | гости пишут текст с телефонов, аватар зачитывает | `prompt`, `read_aloud` |
| `pause` | объявляет паузу (еда, танцы, чай) и молчит | `text`, `minutes` |
| `handoff` | передаёт слово живому человеку и молчит | `text` |
| `settings` | меняет фазу/приём гостей/голос без речи | `phase`, `accepting`, `voice` |

### Подстановки в текстах

`{name}` — имя гостя · `{hero}` — юбиляр · `{count}` — число гостей · `{leaders}` — лидеры ·
`{correct}` — правильный ответ · `{winners}` — сколько угадали · плюс любые ключи из `vars`.
Числительные склоняются автоматически (`plural()` уже есть в `server.py`).

## Как это будет работать в админке

```
[Загрузить сценарий .json]   ← файл читается, валидируется, показывается список шагов

  ▸ 1. Сбор гостей                    [Выполнить]
  ▸ 2. Приветствие гостей по именам   [Выполнить]
  ▶ 3. Первый тост  ← текущий         [Далее ▶]
    4. Викторина                       …

[▶ Далее]  [⏸ Пауза]  [⏭ Пропустить шаг]  [↺ Повторить]  [⏹ Стоп]
```

Главный принцип: **автопилот с ручным подтверждением**. Вечер живой — гости опаздывают,
тост затягивается, торт выносят раньше. Поэтому по умолчанию `auto_next: false`: аватар
отрабатывает шаг и **ждёт**, пока ведущий нажмёт «Далее». Где уместно (например, приветствия
подряд) — ставится `auto_next: true`, и шаги идут сами.

## План работ (когда скажете «поехали»)

| Этап | Что делаем | Объём |
|---|---|---|
| 1 | `scenario.py`: загрузка, валидация схемы, подстановка переменных | ядро |
| 2 | `POST /api/scenario/load` (загрузка файла), `/api/scenario/state`, `/next`, `/prev`, `/goto`, `/stop` | API |
| 3 | Исполнитель шагов: каждый `type` → действия над `EVENT` (речь, квиз, опрос, пауза) | ядро |
| 4 | Вкладка «Сценарий» в админке: загрузка файла, список шагов, кнопки Далее/Пропустить/Повторить | UI |
| 5 | Экран `/host`: показ названия текущего блока, прогресс вечера | UI |
| 6 | Тип `collect` + экран сбора пожеланий на телефоне гостя | функция |
| 7 | Готовые файлы 4 сценариев из каталога в `scenarios/*.json` | контент |
| 8 | Прогон каждого сценария в fast-режиме + дымовые тесты | проверка |

## Что нужно от вас

1. **Какой из 4 вариантов** делаем эталонным первым (или все четыре сразу).
2. **Автопилот или подтверждение** — оставляем `auto_next: false` по умолчанию? (рекомендую да).
3. Нужен ли **редактор сценария прямо в админке** (этап 4 расширенный) или на первом шаге хватит «загрузить готовый .json».
