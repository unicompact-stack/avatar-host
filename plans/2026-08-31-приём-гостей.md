# План: Аватар-хост — приём гостей + приветствие

**Дата:** 2026-08-31
**Статус:** В работе

## Контекст
У нас есть работающий прототип «говорящего аватара» (видео + edge-tts). Нужно добавить приём гостей по QR-коду и приветствие по имени. За основу берём архитектуру kviz-live (QR → код → подключение), но реализуем на Flask/Python.

## Цель
Ведущий запускает приложение → на экране появляется QR-код → гости сканируют, вводят имя → аватар здоровается с каждым по имени.

## Технические решения

### Архитектура
```
┌─────────────────────────────────────────┐
│         Flask-сервер (Python)           │
│  /api/say        → edge-tts → mp3       │
│  /api/guest/*    → QR, connect, join    │
│  /host           → панель ведущего      │
│  /connect        → вход гостя по QR     │
│  /static/videos/ → speaking/awaiting    │
└─────────────────────────────────────────┘
```

### Хранилище
```python
guests = {}  # token → {name, joinedAt, greetedAt}
sessions = {}  # session_id → {role, guestToken}
```

### QR-код
- Генерация через библиотеку `qrcode` (Python)
- URL: `http://{host}:5000/connect?code={code}`
- PNG эндпоинт: `GET /qr?url=...`

### Приветствие
```python
text = f"Привет, {name}! Добро пожаловать!"
# edge-tts → mp3 → фронт воспроизводит
```
