# Сценарий вечера + итоги репетиции (v4.0.0)

**Дата:** 2026-09-03

## Выдуманный вечер, на котором проверяли

**«Юбилей Марии Петровны — 50 лет»**, 6 гостей, зал с проектором.

| # | Фаза | Что делает ведущий | Что делает аватар |
|---|------|--------------------|-------------------|
| 1 | Сбор гостей | открывает `/host` на проекторе, `/admin` на планшете | «Отсканируйте QR и представьтесь» |
| 2 | Приветствия | ничего — идёт само | здоровается с каждым по имени + называет стол |
| 3 | Открытие | «Закрыть приём» | «Все в сборе: сегодня с нами 6 гостей…» |
| 4 | Конкурс | вводит вопрос и варианты | зачитывает вопрос, гости жмут на телефонах, экран показывает столбики |
| 5 | Финал | «Закрыть» с правильным ответом | объявляет победителей и лидеров |

Прогон целиком: кнопка **«▶ Прогнать весь вечер»** в админке или `POST /api/demo/scenario`.

## Что репетиция вскрыла и что уже починено

| Проблема | Решение в v4.0.0 |
|---|---|
| Админка и экран работали только в одном браузере (BroadcastChannel) | SSE `/api/stream` — планшет ведущего, проектор и телефоны видят одно состояние |
| Гости заходят одновременно → реплики накладывались | серверная очередь речи с приоритетами (приветствие важнее болтовни) + один поток-синтезатор |
| Экран закрыли посреди фразы → очередь вставала навсегда | таймаут-страховка `duration + 6s`, очередь идёт дальше |
| Нет интернета → падал весь синтез | офлайн-фолбэк (`tts.py`): шоу продолжается, мимика и субтитры работают, в админке предупреждение |
| `static/audio` рос бесконечно | автоочистка старше часа |
| Браузер блокировал автозвук на проекторе | оверлей «Нажмите для запуска звука» + детект блокировки |
| «Угадали 4 человек», «с нами 1 гостей» | склонение числительных `plural()` |
| Гость обновил страницу — терял сессию | восстановление по `localStorage` |
| Длинный тост валился в один запрос | нарезка по предложениям (`split_text`) |
| Заголовок экрана был захардкожен | правится из админки на лету, как и голос/скорость/тон/лимит |

## Что стоит добавить дальше (по убыванию пользы)

1. **Липсинк по таймингам.** edge-tts отдаёт `WordBoundary` — они уже сохраняются в `synth()["words"]`, но экран их не использует. Можно переключать 3–4 клипа рта по словам.
2. **Персистентность (SQLite).** Сейчас рестарт сервера обнуляет вечер. Для мероприятия на 4 часа — рискованно.
3. **Модерация имён.** Гость может ввести что угодно, а аватар это громко произнесёт при 100 людях. Нужен стоп-лист + режим «сначала одобрить».
4. **Доступ с телефонов в зале.** Wi-Fi площадки часто с изоляцией клиентов; заранее иметь запасной вариант (точка доступа с ноутбука или туннель) и правило в Windows Firewall для порта 8000.
5. **Предзагрузка приветствий.** Синтезировать фразу заранее, как только гость ввёл имя, чтобы не было паузы.
6. **Больше форматов конкурса:** свободный ответ, «кто быстрее», командный зачёт по столам.
7. **Кнопка-паника** у ведущего: мгновенно заглушить аватара (сейчас есть «Стоп + очистить», но хочется физически заметную большую кнопку).
