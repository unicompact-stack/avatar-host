# CLAUDE.md — Аватар-хост

## Описание проекта
Веб-приложение «Говорящий аватар» — ведущий, который приветствует гостей по имени. Гость сканирует QR-код, вводит имя, аватар здоровается нейро-голосом. В дальнейшем — проведение конкурсов и интерактива.

## Стек технологий
- **Python 3** — основной язык
- **Flask** — HTTP-сервер (порт 8000)
- **edge-tts** — синтез речи (Microsoft Neural, бесплатно)
- **qrcode[pil]** — генерация QR-кодов
- **HTML/CSS/JS** — фронтенд (без сборщиков)
- **BroadcastChannel** — связь между вкладками (админка ↔ экран)

## Хранилище данных
- **In-memory** (dict) — гости, токены, сессии, коды доступа
- При перезапуске сервера данные теряются (намеренно для прототипа)

## Роутинг
| URL | Что | Кто видит |
|-----|-----|-----------|
| `/` | Тестовый режим — ручной ввод текста | Разработчик |
| `/host` | Публичный экран — аватар + QR + субтитры | Зрители (проектор/TV) |
| `/admin` | Панель управления — текст, приветствие, настройки | Ведущий (планшет/телефон) |

| `/qr?code=XXXXX` | QR-код PNG | Генерируется для /host |

## Ключевые ограничения
1. **In-memory** — при перезапуске всё стирается
2. **edge-tts неофициальный** — может измениться API
3. **Видео фиксированное** — speaking.mp4 не синхронизировано с текстом
4. **BroadcastChannel** — связь работает только между вкладками одного браузера
5. **Autoplay policy** — браузер может блокировать звук без взаимодействия пользователя

## Архитектура: связь админка ↔ экран
```
Админка (/admin)                     Экран (/host)
    │                                     │
    │  POST /api/say → audio URL          │
    │  bc.postMessage(speak, url)     ───►│  playAudio(url)
    │                                     │  video = speaking
    │                                     │  audio.play() ← звук здесь
    │                                     │  субтитры видны
    │  ◄── bc.postMessage(done) ─────────│  audio.onended
    │  кнопки разблокированы              │  video = awaiting
```

## Важно для новой сессии

### Текущие проблемы (после v4.0.0)
1. **Видео не синхронизировано** — рот не совпадает с текстом (тайминги слов уже есть в `synth()["words"]`, экран их не использует)
2. **Нет персистентности** — рестарт сервера обнуляет вечер
3. **Телефон не подключается к серверу** — Windows Firewall / изоляция клиентов на Wi-Fi площадки
4. **Нет модерации имён** — аватар громко произнесёт что угодно

Решено в v4.0.0: realtime между устройствами (SSE), наложение реплик (очередь), падение TTS без интернета (офлайн-фолбэк), рост `static/audio` (автоочистка), блокировка автозвука (оверлей).

### Как запускать
```bash
cd avatar_host
pip install -r requirements.txt
python server.py
# → Экран:   http://localhost:8000/host
# → Админка:  http://localhost:8000/admin
# → Тест:     http://localhost:8000/
```

### Как тестировать
1. Открыть `http://localhost:8000/host` — публичный экран
2. Открыть `http://localhost:8000/admin` — в другой вкладке
3. В админке ввести текст → "Озвучить" → аватар на экране говорит + субтитры
