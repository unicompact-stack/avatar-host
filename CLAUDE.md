# CLAUDE.md — Аватар-хост

## Описание проекта
Веб-приложение «Говорящий аватар» — ведущий, который приветствует гостей по имени. Гость сканирует QR-код, вводит имя, аватар здоровается с нейро-голосом. В дальнейшем — проведение конкурсов и интерактива для гостей.

## Стек технологий
- **Python 3** — основной язык
- **Flask** — HTTP-сервер
- **edge-tts** — синтез речи (Microsoft Neural, бесплатно)
- **HTML/CSS/JS** — фронтенд (без сборщиков)

## Хранилище данных
- **In-memory** (dict) — гости, токены, сессии (для мероприятия достаточно)
- При перезапуске сервера данные теряются (намеренно для прототипа)

## Структура папок
```
server.py              Flask-сервер: API синтеза + приём гостей
templates/index.html   UI аватара (видео + текст + голос)
static/videos/         видео аватара (speaking.mp4, awaiting.mp4)
static/audio/          сгенерированные MP3
ТЗ-разбор.md           анализ ТЗ и альтернативы TTS
requirements.txt       flask, edge-tts
start.bat              запуск на Windows
_run_bg.py             фоновый запуск сервера
```

## Роутинг
- Вопрос про «сервер / API» → `server.py`
- Вопрос про «фронтенд / UI» → `templates/index.html`
- Вопрос про «TTS / голос» → `server.py` (edge-tts)
- Вопрос про «видео / аватар» → `static/videos/`

## Ключевые ограничения
1. **In-memory хранилище** — при перезапуске всё стирается
2. **edge-tts неофициальный** — может измениться API
3. **Видео фиксированное** — speaking.mp4 не синхронизировано с текстом (Вариант А)
4. **Нет WebSocket** — обновления через HTTP (пока)
5. **Лимит текста** — edge-tts без ограничений, но длинный текст = долгий синтез

## Важно для новой сессии

### Где что лежит
| Что | Где |
|-----|-----|
| Сервер | `server.py` (порт 5000) |
| Фронтенд | `templates/index.html` |
| Видео | `static/videos/` (speaking.mp4, awaiting.mp4) |
| Аудио | `static/audio/` (speech_*.mp3) |
| Настройки | `requirements.txt` |

### Текущие проблемы (над чем работать)
1. **Нет приёма гостей** — нужен QR-код + подключение по имени
2. **Нет панели ведущего** — нет экрана управления
3. **Видео не синхронизировано** — рот не совпадает с текстом (Вариант Б в будущем)
4. **Нет WebSocket** — realtime обновления невозможны

### Как запускать
```bash
cd avatar_host
pip install -r requirements.txt
python server.py
# → http://localhost:5000
```
