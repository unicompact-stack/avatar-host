# Разбор ТЗ + альтернативы синтеза речи

## 1. Что поправить / улучшить в ТЗ

ТЗ в целом рабочее, но есть несколько мест, где прототип «сломается» или будет звучать как робот. По пунктам:

### 1.1 Синхронизация «когда замолчать» — не считай длительность на сервере
Сейчас: «сервер узнаёт длительность аудио и отдаёт команду переключить видео обратно».
Проблема: mp3 от SpeechKit без корректного заголовка длительности → `mutagen`/`ffprobe` могут вернуть 0 или мусор.

**Лучше:** сервер просто возвращает URL аудио, а **фронтенд** слушает событие `ended` у `<audio>` и сам переключает `speaking.mp4 → awaiting.mp4`. Это надёжнее и не требует вычисления длительности вообще.

```js
audio.src = '/static/audio/speech_123.mp3';
video.src = '/static/videos/speaking.mp4';
audio.play();
video.play();
audio.addEventListener('ended', () => {
  video.src = '/static/videos/awaiting.mp4';
  video.play();
});
```

### 1.2 Имя файла `speech.mp3` — перезапись + кэш браузера
Один и тот же `speech.mp3` перезаписывается → браузер кэширует и может проиграть **старое** аудио. Добавь уникальное имя (timestamp/uid):

```python
name = f"speech_{int(time.time()*1000)}.mp3"
```

### 1.3 API-ключ — не хардкодить, и выбрать правильный способ авторизации
- IAM-токен живёт 12–24 часа и требует сервисного аккаунта (лишняя возня для прототипа).
- **Проще:** использовать **API-ключ** (Api-Key, работает для v3) и класть его в переменную окружения / отдельный файл `.env`, а не в `server.py`.

### 1.4 Использовать API v3, а не v1 (голос «как робот» — чаще всего из-за v1)
В v1 остались старые голоса. В **v3** появились новые нейро-голоса (см. ниже) + параметры, которые сильно оживляют речь.

### 1.5 Лимиты v3 и валидация текста
- v3: **250 символов / 24 секунды** на запрос (без `unsafe_mode`), v1 — до 5000.
- Для длинного текста — резать на части и склеивать.
- Отключить кнопку на пустой текст и пока идёт синтез (статус «Генерирую…»).

### 1.6 Автовоспроизведение видео/аудио в браузере
- Видео без звука: `muted + playsinline + autoplay + loop` — иначе некоторые браузеры не заиграют.
- Аудио можно запускать только после действия пользователя — клик «Озвучить» им и является, так что ок.
- Оба видео лучше **preload**, чтобы переключение было без лага.

### 1.7 Вынести настройки голоса в UI
voice / роль (амплуа) / speed / pitch — пусть меняются в админке, а не зашиты в код.

### 1.8 Обработка ошибок
Сеть упала / неверный ключ / превышен лимит → показывать сообщение в интерфейсе, а не ронять сервер.

## 2. Чем заменить синтез, чтобы был «не робот»

Главное правило: «роботом» звучит **старый** (v1, стандартные) синтез и **настройки по умолчанию**. Почти любой современный нейро-TTS на русском будет живее, если выбрать нейро-голос и подкрутить скорость/высоту/паузы.

| Сервис | Качество (рус.) | Цена | Ключ/регистрация | Сложность замены |
|---|---|---|---|---|
| **Yandex SpeechKit v3** (остаться) | Высокое | Платно (≈1.3 ₽/1k симв.) | Да | — |
| **edge-tts (Microsoft neural)** | Высокое, очень живое | **Бесплатно** | Нет (неофиц. API) | Минимальная (1 библиотека) |
| **ElevenLabs** | Максимальное | Платно (~$5/мес) | Да | Средняя |
| **Google Cloud TTS** (WaveNet/Neural2) | Высокое | Платно (есть лимит) | Да | Средняя |
| **Azure Speech** | Высокое (=edge, но офиц.) | Платно | Да | Средняя |
| **OpenAI TTS** (tts-1-hd) | Хорошее | Платно | Да | Средняя |
| **Silero / Piper / RHVoice** | Среднее | Бесплатно, **офлайн** | Нет | Средняя |

### 2.1 Быстрейший способ «не робот» и бесплатно — edge-tts
Тот же прототип, но вместо Yandex — Microsoft neural-голоса, **без API-ключа и оплаты**. Качество на уровне Azure, по-русски звучит почти как человек.

```python
# requirements.txt:  edge-tts
import asyncio, edge_tts

async def tts(text: str, out_path: str, voice="ru-RU-DmitryNeural"):
    await edge_tts.Communicate(
        text=text, voice=voice,
        rate="+0%",      # скорость: "-10%" медленнее, "+10%" быстрее
        pitch="+0Hz",
    ).save(out_path)
```

Русские голоса: `ru-RU-SvetlanaNeural`, `ru-RU-DmitryNeural`, `ru-RU-DariyaNeural`.
Минус: API неофициальный (может измениться), для коммерции — серая зона.

### 2.2 Остаться на Yandex, но оживить (минимум усилий)
В v3 выбери новые голоса вместо старых:
`dasha, julia, lera, masha, alexander, kirill, anton` (v3) — заметно естественнее, чем `oksana/ermil/jane/omazh/zahar` (v1).
Плюс три параметра, которые «убирают робота»:
- **`speed`** — 0.9–1.05 (чуть замедлить → менее механично);
- **`pitch_shift`** — поднять интонационный контур на несколько Гц, голос звучит «живее»;
- **амплуа/роль** — friendly / good / strict меняют эмоциональный окрас.

### 2.3 Максимальное качество — ElevenLabs
Если нужен «вау» и есть бюджет: русские голоса (например Alena, Boris) или Multilingual v2. Платно, но это текущий потолок естественности.

### 2.4 Полностью офлайн (без интернета и оплаты)
`Silero` (ru), `Piper` (`ru_RU-irina-medium`), `RHVoice` — работают локально, текст не уходит в облако. Качество ниже облачных нейро-голосов, но для прототипа «без внешних сервисов» подходит.

**Итог-рекомендация:** для прототипа — **edge-tts** (бесплатно, 5 минут на замену, звучит живо). Для продакшена — **SpeechKit v3** (остаться) с новыми голосами и настройками, или **ElevenLabs** ради максимального качества.
